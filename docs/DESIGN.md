# Design notes

Sorobill frontend visual direction:

- Deep slate / ocean teal palette (Stellar-adjacent — not purple/cream clichés)
- Display font for brand (Syne), readable body (Manrope)
- One composition per viewport on marketing and checkout
- Brand name as a hero-level signal, not only nav text
- Motion for hierarchy (subtle fades/slides), not noise

## Surfaces

| Surface | Tone |
|---|---|
| Landing | Brand-first full-bleed hero |
| Pay checkout | Teal-on-slate hero + subscribe below |
| Dashboard | Functional density OK; keep teal accents consistent |
