# Accessibility

Sorobill aims for usable keyboard and screen-reader paths on public and merchant surfaces.

## Current patterns

- **Skip link** — `SkipLink` in the root layout jumps to `#main-content`.
- **Loading regions** — `LoadingState` uses `role="status"` and a visible label.
- **Errors** — `ErrorState` exposes a title, message, and optional retry control.
- **Live updates** — `announce()` in `src/lib/a11y.ts` writes to an `aria-live="polite"` region during checkout status changes.
- **Forms** — prefer visible `<Label>` + `htmlFor` over placeholder-only fields.

## Checkout checklist

- [ ] Subscribe CTA has an accessible name (`aria-label` when icon-only).
- [ ] Wallet connect announces connection success/failure.
- [ ] Focus moves to `#subscribe` when the hero CTA is used (`focusSubscribe`).
- [ ] Color contrast holds on teal-on-slate pay hero text.

## Testing

Manual: keyboard Tab through `/pay/[planId]` and `/onboarding`. Automated a11y audits (axe) are a future addition; see [TESTING_UI.md](./TESTING_UI.md).
